# Codex Game Studios 项目介绍

## 一句话
在 Codex 里，用完整的游戏工作室流程，把想法推进到有设计依据和验证记录的实现。

## 简短介绍
Codex Game Studios 是基于 Claude-Code-Game-Studios 的非官方开源适配。
它把 49 个专业角色和 74 个工作流接入 Codex，并增加工作室总控、
自动内部衔接和可恢复的进度记录。用户用自然语言提出目标，
不需要逐个操作技能，便可在同一项目中组织策划、数值、UI、架构、
开发和验收。

## 为什么值得尝试
- 可以从“完全没想法”开始，也可以接续已有策划与代码。
- 设计、经济、UI 与技术不再各自独立；变更需要考虑依赖与验收。
- 进度保存在项目中，中断后可以接着做。
- 检查失败或证据缺失不能被标记为完成。
- 只需要 Codex，不需要同时安装另一套 AI 编程产品。

## 适合谁
独立游戏开发者、小型团队，以及想尝试 AI 辅助制作但需要流程和约束的人。
使用者仍需要决定核心方向、评估建议并参与试玩反馈。

## 公开验证说明
当前已通过 24 项离线流程测试、75 个技能格式检查和 105 处阶段引用检查。
这不是“AI 已经自动制作并验证了整款游戏”的承诺。
全部工作流的实战体验、不同引擎兼容性和游戏质量仍需持续验证。
